# 아카이브 — 대체·폐기된 차선 검출 문서

작성일: 2026-07-24

여기 있는 문서들은 **현재 코드에 존재하지 않는 접근/기능**을 기술한다. 역사적 분석·측정 데이터로서 보존하되, 현행 문서로 쓰지 말 것. 살아있는 문서는 상위 폴더 [`docs/lane/`](../) 참고.

## 왜 폐기되었나

두 갈래의 옛 접근이 있었고 둘 다 지금 코드에서 빠졌다.

### 1) `roi_top_ratio` 하단컷 ROI 실험 (전면 폐기)
`LaneConfig.roi_top_ratio` 로 lane_mask 상단을 비율만큼 잘라내는 실험. 스윕 결과 **효과 없음**(차선 픽셀이 하단 ~35%에 몰려 있어 상단컷이 무의미)으로 결론났고, 파라미터·`SetRoiTopRatio()`·`runBagDump()` 덤프모드 모두 코드에서 제거됨. 지금은 대신 **드래그 가능한 쿼드 크롭(PRE/POST)** 으로 대체 → [`../03_설계.md`](../03_설계.md).

| 파일 | 내용 | 상태 |
|---|---|---|
| `roi_dev_plan.md` | 하단컷 ROI 개발계획 | 폐기 (기능 삭제됨) |
| `root_cause_and_improvement.md` | 하단컷이 효과 없던 근본원인 분석 + 개선안 A~D | 역사적 분석 (스윕 데이터 보존 가치) |
| `changelog.md` | S1~S4 스윕 작업 로그 | 역사적 기록 |
| `progress_checklist.md` | 하단컷 작업 체크리스트 | 폐기 |
| `usage.md` | `roi_top_ratio` 실행 커맨드 가이드 | 폐기 (커맨드 무효) → [`../01_사용법.md`](../01_사용법.md) |
| `references.md` | 하단 ROI 정당화 문헌조사 5선 | 문헌 자체는 유효, 전제(하단컷)만 폐기 |

### 2) BEV-mask 런타임 튜닝 UI (대체됨)
`applyRoiMask` 기반 BEV 사다리꼴 마스크를 트랙바/마우스로 실시간 튜닝하던 UI(`renderRoiMaskOverlay`, `ROI Mask Control` 창, `setupRoiTuning`, `onRoiTrackbar`). 좌표계·극성 문제로 **쿼드 크롭 설계로 재설계**되며 심볼 전부 제거됨.

| 파일 | 내용 | 상태 |
|---|---|---|
| `차선ROI.md` | BEV-mask 튜닝 UI 개발계획 | 대체됨 → [`../03_설계.md`](../03_설계.md) |
| `roi 사다리꼴.md` | BEV-mask 튜닝 UI as-built 명세 | 대체됨 (심볼 부재) |

> 참고: `applyRoiMask` 자체와 `roi_half_top_ratio` 등 `LaneConfig` 필드는 아직 코드에 남아 정적 설정으로만 쓰인다 ([`../02_파라미터.md`](../02_파라미터.md) 참고). 사라진 건 "런타임 튜닝 UI"다.
