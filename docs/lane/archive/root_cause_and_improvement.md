## 2. 근본 원인

**유효 차선 픽셀이 640×360 마스크의 하단 ~35%(row ≥ 0.65×360 ≈ 234)에만 존재한다.**

- 상단 65%(row 0~234)는 하늘·건물·원거리로, YOLOPv2 lane mask가 애초에 픽셀을 거의 내지 않는다. → 여기를 잘라도(0.0~0.65) **제거할 픽셀이 없으므로 출력 불변**.
- 0.70부터 컷 선이 근거리 차선 띠를 침범 → view_range가 10m→3m→0m으로 붕괴, degenerate 폭증. 즉 컷은 **노이즈가 아니라 신호(근거리 차선)를 깎기 시작**한다.
- **컷 로직 자체는 정상**(0.90에서 전 NODET). 무효과는 버그가 아니라 **씬/모델의 공간 분포 특성**이다.

### S1 가설의 반증
S1 전제는 "상단 절반은 노이즈원이므로 제거하면 오검출↓·연산↓"이었다. 실측 결과 **상단은 노이즈원이 아니라 빈 영역**이었고, degenerate(P2)의 원인은 상단 노이즈가 아니라 **하단 근거리 밴드의 ill-conditioned 3차 피팅**이다. → 세로 방향 하단 ROI로는 P2·P4 어느 것도 개선 불가.

### 레퍼런스와 대조
- **#4 UFLD(row-anchor 세로 한정)**: 세로 범위 한정은 이미 마스크가 사실상 달성(하단 35%). 추가 컷으로 얻을 이득 없음 — 관측과 일치.
- **#5 YOLOPv2(풀프레임 학습)**: 마스크 후처리 컷을 택한 4.2 결정은 옳았으나(입력 크롭 리스크 회피), 그 대가로 **컷이 무해한 동시에 무익**했다.

## 3. 개선 방안 (레퍼런스·기획서 근거)

세로 하단 ROI는 **종료**한다. 실측이 개선 여지 0을 입증. 대신 아래로 우선순위를 전환한다.

### 개선 A — P2 degenerate 하드게이트 (최우선, 근거: ACSNet #3 + 0709 P2)
degenerate의 실체는 근거리 소수 픽셀의 3차 overfit. ACSNet #3은 ROI를 "자르기"가 아니라 **"어디를 얼마나 신뢰할지 가중"**으로 쓸 때 night −50%·noline −35%를 보고 — 우리 근거리 가중 피팅과 방향 일치.
- **저-span·고-곡률 게이트**: `span_m < valid_view_range(≈5m)` 또는 `|coeffs[0]|`(곡률)·`|coeffs[3]|`(횡offset) 임계 초과 시 NODET/availability=0 강제.
- **차수 자동 강등**: 점 수/커버리지 부족 시 3차→1~2차 피팅으로 강등해 overfit 폭발 차단.
- 대상: `LaneDetection.cpp` `validateAndSmooth`/게이팅, 파라미터 `span_min_m_*`, `valid_view_range`, `rmse_hard_bad_m`.
- 기대: degenerate 245→대폭↓, pos/head std 정상화(P1과 함께).

### 개선 B — P1 계수→필드 매핑 off-by-one 교정 (독립·필수)
`helper_lane.cpp buildCam2LD`가 `position=coeffs[2]`(heading slope), `heading=coeffs[1]`(곡률)로 한 칸씩 밀려 매핑. 물리적으로 `position=coeffs[3]`(횡offset), `heading=coeffs[2]`여야 함. 소비단(SF/planning)과 **동시 반영** 필요. (ROI와 무관하나 std 절대값을 지배하는 진짜 원인.)

### 개선 C — P4 원거리 커버리지 (근거: 관측 + DROI #2)
마스크가 ~10m 이후 차선 픽셀을 거의 못 내는 것이 핵심 한계(vr median 10m ≪ roi_xmax 70m). 세로 컷과 무관한 별개 문제.
- **원인 분리 진단**: (a) YOLOPv2 far-field 세그 약함인지, (b) mask→BEV 호모그래피가 원거리 지면을 마스크 상단 빈 strip으로 매핑하는지 구분.
- (a)면 mask far-field 임계 완화/입력 해상도, (b)면 BEV 원거리 해상도·`strip_*` 재튜닝.

### 개선 D — ROI를 살린다면: 세로 컷이 아닌 적응형 횡 ROI (근거: A-ROI #1, DROI #2)
정적 세로 컷은 폐기하되, 레퍼런스가 성능을 입증한 방향은 **이전 프레임 차선 기반 적응 ROI**와 **곡선로 좌우 마진 동적화**다.
- 직전 프레임 `coeffs`로 다음 프레임 좌우 탐색 밴드를 좁혀 오검출 억제(#1), 곡선에서는 좌우로 넓혀 놓침 방지(#2).
- 이는 세로가 아닌 **횡(가로) 방향** 제약이라, 하단 35% 밴드에 신호가 몰린 현 분포와 충돌하지 않는다.
- 기획서 S5에 해당. B/C 이후 착수.

## 4. 권고 우선순위

1. **B(P1 매핑)** + **A(P2 게이트)** — 지표 정상화의 실제 지렛대. ROI와 독립적으로 즉시 효과.
2. **C(P4 원거리)** — 커버리지 근본 한계 진단.
3. **D(적응형 횡 ROI)** — A~C 후, ROI 방향을 세로→적응형 횡으로 재설계.

세로 하단 ROI(S1) 및 ratio 스윕(S3)은 여기서 **종료**한다.
