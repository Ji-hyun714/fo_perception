# 프레임 뷰어 × ROI 필터 × 관리 패널 통합 개발계획

## 0. 목표
지난 세션의 **프레임 단위 bag 뷰어**(`runBagViewer`)와 현재의 **ROI 사다리꼴 필터**를 통합하고,
그 위에 **rviz2 를 간략화한 "관리 패널(Control Panel)"** 을 얹는다.

- **관리 패널바**: 마우스 클릭으로 각 시각화(레이어)를 켜고 끄는 토글 목록 (rviz2 Displays 패널의 경량판).
- **캔버스**: bag 원본 + 선택된 시각화를 함께 보여줌.
- **팝업 창**: 각 시각화는 독립 창으로 뜨고 **창 크기 조절 가능**(`cv::WINDOW_NORMAL`).
- OpenCV HighGUI 기반(노드 내장). Qt/rqt/RViz 별도 앱 아님.

## 1. 토글 레이어 목록 (요청 확정)
| # | 레이어 | 내용 | 소스 |
|---|---|---|---|
| L1 | 원본 + ROI 사다리꼴 | 원본 프레임 + 사다리꼴·꼭짓점 오버레이(마우스 편집) | `drawQuadEditor` |
| L2 | Zoom 뷰 | ROI 사다리꼴을 직사각형으로 편 미리보기 | `drawZoomView` |
| L3 | BEV 뷰 | 캘리브 기반 조감도 | `drawBevView` |
| L4 | 검출결과 + 정보패널 | 차선 피팅·객체 bbox + 프레임/재생/상태 패널 | `runFramePipeline`+`renderInfoPanel` |
| L5 | 파이프라인 중간단계 | lane_mask / sobel / HLS / bev_bin / sliding-window 등 | lld_ `getDebugImage` (`show_*`) |

## 2. 관리 패널(Control Panel) 설계
- 별도 창 `Control Panel` — 세로로 **버튼(레이어명 + ON/OFF 색)** 나열.
- **마우스 클릭 히트박스**: 각 버튼 사각영역을 클릭하면 해당 레이어 토글. (직접 그린 GUI)
  ```
  struct PanelButton { cv::Rect rect; std::string label; bool* flag; };
  onPanelMouse: 클릭 좌표가 어느 버튼 rect 안인지 검사 → *flag 반전
  drawPanel: 버튼마다 rect 채우기(ON=초록/off=회색) + 라벨
  ```
- L5(중간단계)는 하위 세부 토글(lane_mask/sobel/HLS/…)을 접이식으로 or 별도 행으로.
- 프레임 뷰어 컨트롤(재생/정지, 배속)도 패널 하단 버튼으로 노출(선택).

## 3. 팝업 창 & 크기 조절
- 각 레이어 창은 `cv::namedWindow(name, cv::WINDOW_NORMAL)` → **사용자 드래그로 크기 조절**.
- 토글 ON → `imshow`, OFF → `cv::destroyWindow`.
- 최초 1회 `cv::resizeWindow` 로 기본 크기 배치(겹침 방지 offset).
- 표시 배율 파라미터: `display_scale`(내용 렌더 배율)와 창 크기(사용자 조절)는 분리.

## 4. 파이프라인/뷰어 통합 (이전 계획 유지)
- **`runFramePipeline(frame,header,&result,&debug)` 공용화** + PRE/POST ROI 크롭을 그 안으로 이동
  → 구독/뷰어 두 경로 공통 적용.
- **`runBagViewer`** 이식: rosbag2 로 프레임 순회, ←/→·GOTO·배속·트랙바.
  - 뷰어는 자체 while + `waitKeyEx` → spin 없이 도므로 **패널·레이어 렌더·마우스콜백을 루프 안에서 직접** 처리.
- `main`: `bag_path` 있으면 `runBagViewer`, 없으면 `spin`(구독).
- 소스 출처: 프레임 뷰어 원본은 커밋 안 됨 → `~/.claude/file-history/5d546aa3-.../b79ce4060e057577@v9`(1011줄) 참조 이식.

## 7. 통합 키맵 (마우스 패널이 주, 키는 보조)
| 입력 | 기능 |
|---|---|
| 패널 버튼 클릭 | 레이어 토글 (마우스 GUI) |
| 캔버스 좌드래그 | ROI 꼭짓점 이동 |
| ← / → , Space, `,`/`.`, 숫자+Enter | 프레임 탐색 / 재생 / 배속 / GOTO |
| `s` / `l` | ROI 프리셋 저장 / 불러오기 |
| q / Esc | 종료 |
- 기존 `p o z b r`(키 토글)는 패널 버튼으로 대체되지만 **단축키로도 유지**.

## 8. 작업 순서 & 검증

## 9. 리스크 / 확인
- 창 다수 + 마우스콜백 다수 → 창별 `setMouseCallback` 관리. 패널/캔버스 클릭 구분.
