## 1. 빌드

`utils` 패키지 때문에 **워크스페이스 install도 반드시 source** 해야 한다.

```bash
cd /home/wise/fo_perception
source /opt/ros/humble/setup.bash
source install/setup.bash          # ← utils 등 워크스페이스 패키지
colcon build --packages-select lane_detection
source install/setup.bash          # 빌드 후 재소스
```

## 2. 실행 — 두 가지 모드

`main()`이 `bag_path` 파라미터 유무로 분기한다 ([03_설계.md](03_설계.md) §1).

### (A) LIVE 모드 — 토픽 구독
```bash
ros2 run lane_detection yolopv2_cam2_node --ros-args \
  -p debug_mode:=true
```
`/camera/image_rect` 를 구독하며 spin. 30ms 타이머가 GUI 렌더/키 입력 담당.

### (B) BAG 뷰어 모드 — bag 프레임 단위 재생/탐색 (권장 검증 경로)
```bash
ros2 run lane_detection yolopv2_cam2_node --ros-args \
  -p bag_path:=/home/wise/fo_perception/7_to_hoamji \
  -p bag_topic:=/camera/image_rect \
  -p debug_mode:=true
```
노드가 bag을 **직접 읽어** 프레임 단위로 순회한다(`runBagViewer`). **별도 `ros2 bag play`·rviz2 불필요.**
`bag_topic` 기본값은 `/camera/image_rect`.

## 3. 관리 패널 (Control Panel)

`Control Panel` 창에 **마우스 클릭 토글 버튼**이 그룹별로 있다. 프레임 탐색 **트랙바("frame")도 이 창 상단**에 붙는다.

| 그룹 | 버튼 |
|---|---|
| LAYERS | `ROI Editor` · `Zoom` · `BEV` · `Process` · `Info Panel` · `Legend` · `Structure` |
| ROI CROP | `PRE crop` · `POST crop` |
| PROCESS STAGES | `mask` · `bev` · `sobel` · `bev_bin` · `sld_win` · `hls` · `contour` |

- 각 레이어는 **독립 팝업창**(`WINDOW_NORMAL`) → 드래그로 **크기 조절 가능**.
- **창을 X로 닫으면** 해당 레이어가 자동으로 off로 내려간다 → 다음 프레임에 다시 안 뜬다 (`syncClosedWindows`).
- PROCESS STAGES 토글은 `Lane Detection Process` 모자이크에 나타나는 중간단계를 켜고 끈다.

### 창 목록
`Control Panel`(패널+트랙바) · `ROI Quad Editor` · `ROI Zoom View` · `BEV View` · `Lane Detection Process`(파이프라인 모자이크) · `Lane Info Panel`(config+result 값) · `Pipeline Structure`(라이브 구조도).

## 4. 키맵

| 입력 | 기능 |
|---|---|
| `Space` | 재생 / 정지 (BAG 모드) |
| `←` / `→` | 이전 / 다음 프레임 |
| `↑` / `↓` 또는 `,` / `.` | 배속 −/＋ (0.1 ~ 4.0) |
| 숫자 + `Enter` | 해당 프레임으로 GOTO |
| `Backspace` | GOTO 입력 지움 |
| `q` / `Esc` | 종료 |
| `p` / `o` | ROI PRE / POST 크롭 토글 |
| `z` / `b` | Zoom / BEV 뷰 토글 |
| `r` | ROI 사다리꼴 기본값 리셋 |
| `s` / `l` | ROI 프리셋 저장 / 불러오기 |

> 패널 버튼 클릭이 주 조작, 키는 보조. 마우스 콜백은 창별로 분리되어 있다.

## 5. ROI 편집

`ROI Quad Editor` 창에서 사다리꼴 **꼭짓점(TL/TR/BR/BL)을 드래그**로 이동. 드래그 종료 시에만 ROS 파라미터에 반영(콜백 폭주 방지).

- **PRE crop**: 추론 입력 자체를 사다리꼴 안쪽만 남기고 크롭.
- **POST crop**: 추론은 풀프레임으로 돌린 뒤 결과 `lane_mask`에서만 바깥 제거.

의미·설계는 [03_설계.md](03_설계.md) §3 참고. 관련 파라미터: `roi_quad_enable_pre/post`, `roi_quad_pts`, `roi_quad_preset_path`, `roi_quad_display_scale`, `debug_window_scale`(기본 0.6).

## 6. 검증 절차

1. 대상 bag(예: `7_to_hoamji`) 을 BAG 뷰어 모드로 연다.
2. `←`/`→` 로 프레임을 넘기며 **차선 피팅**(`Lane Detection Process` / `Lane Info Panel`)을 확인.
3. `PRE`/`POST` 크롭을 토글하며 차선 검출 안정성 변화를 관찰.
4. `Lane Info Panel` 의 `LaneResult`(state_L/R, quality, rmse_fit_m, pixel_count, lane_start/end_m 등)과 `LaneConfig` 값을 점검 ([02_파라미터.md](02_파라미터.md)).

## 7. 발행 토픽

| 토픽 | 타입 | 비고 |
|---|---|---|
| `/camera/lane_result` | `fo_msgs/Cam2LD` | 차선 검출 결과 |
| `/camera/cam2data` | `fo_msgs/Cam2Data` | LD+TD+TL+OD 통합 |
| `/camera/sf_objs` | `fo_msgs/Cam2DataForSF2` | SF용 객체 |
| `/camera/det_bboxes` | `sensor_msgs/Image` | debug 전용, bbox 오버레이 |
| `/camera/lane_marker` | `visualization_msgs/MarkerArray` | debug 전용, RViz 마커 |

입력: `/camera/image_rect` (`sensor_msgs/Image`, LIVE 모드 구독).

## 8. 트러블슈팅

- **빌드 중 `Could not find package "utils"`** → 빌드 전 `source install/setup.bash` 누락. §1 순서대로.
- **bag 뷰어에 프레임 0개** → `bag_topic` 이 실제 bag의 이미지 토픽과 다름. `ros2 bag info <bag>` 로 토픽 확인.
- **bag 열기 실패** → rosbag2 storage 플러그인(mcap/sqlite3) 설치 여부 확인.
- **창이 안 뜸** → `debug_mode:=true` 인지 확인.
